# Decline — this is an archive, not a system

I was pointed at a personal file drawer and asked for a map. I will not draw one, because there
is nothing here to wander.

## What is here
Unrelated personal files: a resume, tax paperwork, financial statement exports, a few photos, a
folder of confirmations. Real things — each one stands entirely on its own.

## Why it is not mappable
The nouns **do not move each other.** Changing the resume does not touch the tax paperwork;
deleting a photo moves nothing else; the financial exports feed no other file in the folder. With
no movements, every card's "what else moves" line would be empty — and a map whose cards have no
movements is a glossary, not a map. Drawing roads between these files would be a fake city.

(Note: this folder also holds sensitive documents — recovery codes, tax records. Even if it
*were* a system, those would be excluded from any published map. A cartographer names its
exclusions; it does not copy secrets into cards.)

## What a mappable territory would look like instead
Point me at a folder where **changing one thing touches another**: a repo where a config feeds an
engine, a delivery folder where a consent form gates an invoice, an automation pack where a
webhook fires a sequence. If you touch a noun and something else must move, I can map it — see
`receipts/vendor-lilly/` for what that looks like.
