# Decline — this is an archive, not a system

I was pointed at a folder and asked for a map. I will not draw one, because there is no map here
to wander.

## What is here
A pile of unrelated files: a resume, a tax PDF, a few photos, a folder of receipts. Real things,
but each one stands alone.

## Why it is not mappable
The nouns **do not move each other.** Changing the resume does not touch the tax PDF; deleting a
photo moves nothing else. With no movements, every card's "what else moves" line would be empty —
and a map whose cards have no movements is a glossary, not a map. Inventing roads between these
files would be a fake city.

## What a mappable territory would look like instead
Point me at a folder where **changing one thing touches another**: a repo where a config feeds an
engine, a delivery folder where a consent form gates an invoice, an automation pack where a
webhook fires a sequence. If you touch a noun and something else has to move, I can map it.
